**Problem:** Too Many Books (Longest Increasing Subsequence)

**Topic:** Dynamic Programming & Binary Search

**Algorithm Logic:**
Bypassed the standard O(N^2) Dynamic Programming solution to avoid Time Limit Exceeded (TLE) errors. Implemented an O(N log N) algorithm using an auxiliary `tails` array. The array dynamically tracks the smallest possible ending values for increasing sequences. For each element, a binary search finds its optimal placement, either extending the max sequence length or overwriting a previous value to establish a more optimal base for future sequence growth.

**Key Learning:**
An array tracking state does not always represent the literal elements of the final sequence. In the LIS binary search method, the `tails` array correctly tracks the *length* of the longest sequence, even if the elements inside it get overwritten and no longer form a valid sequence themselves.
